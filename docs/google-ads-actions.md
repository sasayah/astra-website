## 3. サイト側（本リポジトリ）で必要な作業

調査の結果、**Google広告のために新規実装が必要なものは無い**。確認済み事項:

- Google広告が使っていたLP 10本（`/huyouhin2` `/huyouhin` `/huyouhin2-line` `/huyouhin2-form` `/hoarding-form` `/moving` `/ihinseiri` `/huyouhin-ph` ほか）は**すべて新サイトに存在**。切替後の404は発生しない。
- 各LPに tel:リンク / line.meリンク / `id=submit_button` / `class=input-service` が残っており、**GTMの5つのCVトリガーはそのまま発火する**。
- 新規の品目LP（`LpTemplate` / `LpTemplateB`）にも同じフックが実装済み。
- 唯一の依存は `NEXT_PUBLIC_GTM_ID`。未設定だと Yahoo だけでなく **Google広告のCVも全て失われる**（1-4参照）。
