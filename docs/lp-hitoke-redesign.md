## 配信設計（2026-08-09 更新: 全品目展開）

**品目分割A/Bは取りやめ、全16品目に展開した**（オーナー判断）。

理由: 単品キャンペーンのCVは2週間で片群10数件しか貯まらず、統計的有意差が出ない。
群を分けても効果を切り分けられないため、全トラフィックに当てて月次の前後比較で見る方針。

- 配信対象: `ALL_SLUGS`（16品目）= A案 `/lp/{item}`・B案 `/lp/b/{item}`・地域LP `/lp/{item}/{city}` すべて
- **ロールバック**: `HITOKE_SLUGS` を `new Set<string>([])` にするだけ。部分配信に戻す場合も残したいslugだけ列挙する
- 見るべき指標: 電話タップ率・LINEタップ率・CPA・ROAS（月次で前後比較）。
  補助として直帰率・スクロール到達（GA4/Clarity）
- 悪化した場合の判断: 大きく悪化したらロールバック。ただし季節・入札・予算の変動と混ざるため、
  単月の悪化だけで即断せず、広告側の変更履歴（`yahoo-ads-actions.md`）と突き合わせること

## 憲法（レビュー3視点＋反証検証済み）

1. キャラ登場上限: A案4箇所 / B案2箇所（実装値で固定）
2. 料金表・許可情報・比較表の数字・クチコミ枠にキャラを入れない
3. 吹き出し＝事業者の主張のみ（サイネージ紹介/年中無休で電話受付/日時指定/0円/搬出対応/LINE写真/女性スタッフ受付）。体験談・創作の声は禁止。**「24時間」は事実と異なるため使用禁止**
4. キャラ幅38%上限・FVはH1＋円バッジ＋電話CTA導線を確保（追従フッターCTAあり）
5. 広域LP（kagu/kaden）は「最短20分」を出さない（LpBadges3 の wide、AstoKun吹き出しには速度表現なし）
6. クチコミ枠（グレー枠＋Google出典）とキャラ吹き出し（黄枠＋丸ゴ）の様式分離

7. **クチコミには人物イラストを使わない** — 実在のGoogleクチコミ投稿者の年齢・性別を推測した似顔絵は作らない。投稿者名の頭文字＋名前由来の配色のみで人格を出す（Google上の表示と同じ考え方）
8. **図解に価格・条件・電話番号を焼き込まない** — SEO・スクリーンリーダー・修正容易性・A/Bのため、必ずHTML側テキストで併記する

## アセット制作の実績

外注・画像生成AIとも使わず、**全点コードSVG**で内製（費用0円）。
キャラ6ポーズ＋品目16＋人物6＋作業員4＋図解5系統＝計40点超。
1点あたり数KBでLCPに影響せず、修正はコード編集で即時。画像生成にありがちな「顔ブレ」が構造的に発生しない。

## 広告との整合性 — 要対応

### A. 広告文の「24時間」（**要オーナー対応・最優先**）
LPから削除したため、**広告文（RSA）に「24時間受付」が残っていると広告とLPが矛盾する**。
管理画面のセッションが切れており本チェックでは確認できなかった。
→ 広告（`/list/ads/`）と広告表示アセットを「24時間」で検索し、あれば「年中無休」に修正すること。
　 事実と異なる表示のため、広告側も景表法の対象。

### B. A/Bテストの評価対象から除外すべき品目
現在の分割（`lp-hitoke.ts`）と実際の広告トラフィックに乖離がある。

| 品目 | 群 | 実態（`yahoo-ads-actions.md` 30日実績より） |

| kaden | 対照 | 広域LP（関西全域）。同上 |
| monitor | 新 | 液晶グループ **CV0** |

| sentakuki | 新 | 8/8にnegative削除で**4年半ぶりに配信再開**したばかり。立ち上がり途中 |

→ **判定は単品キャンペーンの品目のみで行う**こと。実質の比較対象は
　 新: reizouko / tansu / sofa / jitensha / desk ↔ 対照: aircon / tv / mattress / piano / futon / bed
