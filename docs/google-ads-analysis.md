### 問題点

1. **CV価値の8割超（LINE ¥11.4M）と電話クリック（¥376k）が「サブ」**＝スマート入札の最適化対象外。メインは合計620件・¥864k程度しかない。この状態で「コンバージョン数の最大化」を再開すると、**学習対象がほぼ空のまま配信が始まる**。
2. 「通話ボタンをクリック」「Business profile - Call」の**CV価値が¥1**。設定ミス。
3. **「転送電話番号」が「要確認」**（タグ無効）。アカウント診断の「タグが無効になっています 1」はこれ。
4. 「簡易フォーム送信」は GTM が **ボタンのクリック時**に発火する設定。バリデーション落ち・送信失敗でも1件計上される（Yahooは送信成功時に発火。**同じフォームで媒体間の定義がずれている**）。
   - 新サイトは送信成功時に `dataLayer.push({event:'simple_form_submit'})` を出している（`app/lib/yahoo.ts`）ので、GTM側のトリガーを差し替えるだけで成功ベースにできる。
5. **CV価値がYahooと不整合**。Yahoo: 電話¥10,000 / LINE¥3,000 / フォーム¥3,000。Google: 電話クリック¥1,000 / LINE¥2,850 / フォーム¥6,667 / 入力開始¥2,000 / 通話¥1。→ **媒体間のROAS比較が成立しない**。
6. 全アクションが「最近のコンバージョンはありません」＝現在計測は完全に停止（配信が無いため当然だが、再開時に生きているかは切替後に要確認）。
